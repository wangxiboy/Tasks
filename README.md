## 功能特性

### 任务一：uC/OS-III 移植 + 多任务

- 将 **uC/OS-III** 移植到 STM32F103C8T6（Cortex-M3 / ARMv7-M），Keil ARMCC 工具链；

- 构建 **3 个并行任务**，由 RTOS 抢占式调度：

  | 任务        | 优先级 | 周期 | 动作                                       |
  | ----------- | ------ | ---- | ------------------------------------------ |
  | AppTaskLED1 | 3      | 1 s  | 翻转 LED0（PB0）                           |
  | AppTaskLED2 | 4      | 3 s  | 翻转 LED1（PB1）                           |
  | AppTaskUART | 5      | 2 s  | 串口发送中文（任务一）/ 温湿度（任务二.3） |

### 任务二：AHT20 温湿度采集
- 用**软件 I2C**（GPIO 模拟，规避 F1 系列硬件 I2C bug）读取 AHT20 温湿度；
- **每 2 秒**采集一次，通过串口发送到上位机（Windows 10）；
- 任务二.3：在 uC/OS 多任务基础上，把第 3 个任务改为每 2 秒采集温湿度并输出。
